## 🤖 Claude

Here's how the `desktop` flag works in PR #579:

**The `desktop` boolean** is calculated by the `svelte-toc` library (v0.5.9) based on:

```
desktop = (window.innerWidth > breakpoint)
```

**In this PR:**

1. The `breakpoint` prop is set to `1250` (see commit 7/9):
   ```svelte
   <Toc
     breakpoint={1250}
     bind:desktop
     ...
   />
   ```

2. The library's `Toc` component internally:
   - Monitors `window.innerWidth` reactively
   - Sets `desktop = true` when viewport width > 1250px
   - Sets `desktop = false` when viewport width ≤ 1250px

3. The local component then uses `bind:desktop` to receive this calculated value and conditionally renders:
   - **Desktop** (`desktop === true`): Fixed left sidebar (`.desktop-toc-wrapper`)
   - **Mobile** (`desktop === false`): Floating button with popup (`.toc-wrapper`)

The breakpoint was initially set to 1400 by Wituareard (commit 6/9), then reduced to 1250 by Patricio (commit 7/9) to show the desktop sidebar on narrower screens.
