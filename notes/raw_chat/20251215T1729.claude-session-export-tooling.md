## 🤖 Claude

Yes, the JSONL logs capture everything you need:

**Log location**: `~/.claude/projects/<encoded-path>/<session-uuid>.jsonl`

**Contents** (one JSON object per line):
- `type: "user"` - Your messages (in `message.content`)
- `type: "assistant"` - My responses (in `message.content`)
- `type: "summary"` - Session title
- `type: "file-history-snapshot"` - File state for undo

**Key fields**:
- `timestamp` - When each message occurred
- `sessionId` - Groups messages by session
- `uuid` / `parentUuid` - Message threading
- `version` - Claude Code version

So you could extract a readable transcript with something like:

```bash
cat session.jsonl | python3 -c "
import sys, json
for line in sys.stdin:
    obj = json.loads(line)
    if obj['type'] in ('user', 'assistant'):
        role = obj['type'].upper()
        content = obj['message'].get('content', '')
        if isinstance(content, list):
            content = ' '.join(c.get('text','') for c in content if c.get('type')=='text')
        print(f'=== {role} ===\n{content}\n')
"
```

This is more reliable than `script -f` and captures the actual conversation structure. You can update your CLAUDE.md to remove the script reminder if you prefer this approach.
