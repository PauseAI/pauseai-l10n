# L10N Model Migration Planning

**Date:** 2026-03-05
**Branch:** main (cleaned up `join-operations` which had been merged)

## Decisions Made

### Model migration: Llama 3.1 405B → Gemini 2.5 Flash
- Current model (`meta-llama/llama-3.1-405b-instruct` via OpenRouter/Fireworks) is out of credits
- Recommended replacement: **Google Gemini 2.5 Flash** (`google/gemini-2.5-flash-preview`)
- Rationale: strong multilingual coverage, fast, cheap (~$0.15/M input, $0.60/M output), good instruction following (should fix Llama's URL-translation problem)
- At 30 locales: ~$4.50/month incremental, ~$7.50 for full retranslation
- Keep OpenRouter as proxy — 5.5% overhead is negligible at this volume, and model swapping stays trivial

## Topics Discussed But Not Actioned

- **ELI5 / audience-adaptive translation:** Gemini Flash capable enough; `promptAdditions` system already scaffolded for per-page/per-language prompt extras; routing/UX is the harder question
