Bits and pieces session: investigated excessive share tracking duplicates, implemented 60-second deduplication using SQS timestamps, applied retroactive cleanup, fixed unpublished collage bug, sent test emails.

## Key Achievements

### 1. Share Tracking Duplicate Investigation

**Discovered**: Day-after tracking stats showed 124 shares from only 2 users
- mail@anthonybailey.net: 123 shares across 5 platforms
- tom@pauseai.info: 1 share (Twitter)

**Root cause**: Tab reloads, browser refresh, multiple clicks all recorded as separate shares
- Example: Opening LinkedIn share link once → 3 HTTP requests → 3 database records

### 2. 60-Second Share Deduplication Implementation

**Problem**: Queue delays meant comparing processing times, not actual click times
- User clicks at 15:54:00 → processed at 15:54:15
- User clicks at 15:54:05 → processed at 15:54:50
- Time diff appeared to be 35s but actual clicks were 5s apart

**Solution**: Use SQS message `SentTimestamp` (when queued) not processing time

**Changes**:
- **TrackingDB** (`lib/tracking.py`): All methods accept optional `event_time` parameter
  - Event timestamps (`shared_at`, `opened_at`, etc.) use `event_time` if provided
  - Metadata timestamps (`updated_at`) still use real clock for database auditing
- **Tracking worker** (`scripts/tracking_worker.py`):
  - Extract `SentTimestamp` from SQS message attributes
  - Pass `event_time` to all handlers
  - Share handler checks last share, ignores if within 60s window
  - Changed duplicate logs from DEBUG to INFO level for visibility
- **Stats reporting** (`scripts/check_tracking_stats.py`):
  - Show unique user+platform combinations vs total clicks
  - Platform breakdown shows users + click counts

**Example output**:
```
Shared: 2 users, 6 unique user+platform combinations (52 total clicks)
  - twitter: 2 users (12 clicks)
  - facebook: 1 users (13 clicks)
  - linkedin: 1 users (12 clicks)
  - whatsapp: 1 users (8 clicks)
  - reddit: 1 users (7 clicks)
```

### 3. Retroactive Cleanup

- Applied to mail@anthonybailey.net testing data
