## Key Decisions

1. **localStorage vs cookies**: Chose localStorage for simpler client-side API
   - Future: Client can send UID to server API for personalized collage rendering

2. **detectAndStoreCollagenUid() semantics**: Only returns true for URL params
   - Prevents validate/subscribe action confusion
   - localStorage is for future use, not current page context

3. **S3 latest/ placeholder strategy**: Upload manual collages as placeholders
   - Unblocks website integration
   - Will be replaced when automated collage published

4. **Link component S3 detection**: Inline check, no separate method
   - Pattern works for both URL styles
   - /pauseai- substring catches protocol slashes in virtual-hosted style

5. **DERIVATIVE_SIZES constant**: Single source of truth
   - Prevents drift between generator and upload script
   - Documents rationale for each size
