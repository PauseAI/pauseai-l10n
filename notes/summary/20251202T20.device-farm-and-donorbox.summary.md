## Completed: AWS Device Farm iOS Safari Testing

### Background
Playwright WebKit doesn't catch all iOS Safari layout issues. The QuotesCarousel `margin: -20px` overflow bug (#562) was missed by Playwright but visible on real iOS devices.

### What Was Built
- Set up AWS Device Farm with dedicated IAM user (`pauseai-devices`) and CLI profile (`device-testing`)
- Created Appium-based automated testing scripts in `scripts/device-farm/`
- Validated by reproducing the #562 bug on `deploy-preview-564` vs production

### Key Technical Details
- Device Farm only available in `us-west-2`
- Uses `remoteDriverEndpoint` for Appium client to control remote iOS devices
- Session timeout: 5 min inactivity
- Cost: ~$0.17/min, 1000 free minutes/year
