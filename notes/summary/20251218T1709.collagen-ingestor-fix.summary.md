# Collagen Ingestor Fix & New Collage Build

**Date:** 2025-12-18
**Session:** collagen-ingestor-fix

## Summary

Fixed 40-day outage of collagen ingestor service, recovered 41 missing tiles, built and published new 330-tile collage.

## Root Cause Analysis

The ingestor had been crash-looping since **Nov 8 15:44** (not Nov 4 as initially thought). Two issues:

1. **Missing SQS env var** - When `redirect-logs-to-efs.sh` was run on Nov 8, the service restarted but `SQS_QUEUE_URL` wasn't in `.env`

2. **Inline comments in .env** - The `.env` file had inline comments like:
   ```
   CLOUDINARY_API_KEY="779717836612829"  # Anthony's test account
   ```
   systemd's EnvironmentFile parser includes everything after `=` literally, so credentials were corrupted.

## Fixes Applied

### On EC2:
- Fixed `.env` format (no inline comments, no quotes)
- Added `SQS_WEBHOOK_QUEUE_URL`
- Added `COLLAGEN_DATA_DIR=/mnt/efs` to `.bashrc`
- Removed allowlist file to enable production email sends
