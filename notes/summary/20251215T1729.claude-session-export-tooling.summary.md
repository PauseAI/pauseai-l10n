# Session: Claude Session Export Tooling

**Date:** 2025-12-15
**Branch:** main (up to date)

## Summary

Set up tooling to export Claude Code session logs and established an end-of-session workflow.

## Decisions Made

1. **Log parser choice:** Selected `claude-conversation-extractor` (via uvx) over `claude-code-log` because it outputs markdown (vs HTML only), better suited for the existing `raw_chat/` convention.

2. **Installed `uv`** - modern Python tooling that provides `uvx` for running CLI tools without polluting the environment.

3. **Created `export-claude-session` script** (`~/repos/main/bin/`):
   - Auto-detects project from current working directory
   - Exports to `~/repos/pauseai-l10n/notes/raw_chat/YYYYMMDDTHHMM.session-name.md`
   - Minute-precision timestamps allow multiple exports per session (pre-compact + end)

4. **Updated main `~/.claude/CLAUDE.md`:**
   - Replaced outdated `script -f` workflow
   - Added "Adieu" section documenting the 3-step end-of-session process
   - Mirrors the existing "Greetings" hook at session start

5. **All session logs centralized** in `pauseai-l10n/notes/` regardless of which project the session was in (Anthony's existing convention).

## Current Status

- Workflow is functional and tested
- Script located at `~/repos/main/bin/export-claude-session` (SVN-tracked, in PATH)
- This summary is the first real use of the Adieu workflow
