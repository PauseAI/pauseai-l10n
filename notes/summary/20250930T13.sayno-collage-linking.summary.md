### Technical Debt Resolution

**1. Node Version Management**
- **Issue**: Claude Code's Bash tool doesn't auto-load `.bashrc`, so nvm wasn't available
- **Solution**: Manually sourced nvm in persistent shell session
- **Note**: Shell reverts to v18 between sessions; Node 24 required for `pnpm install`
- **Command**: `export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh" && nvm use`
- **Status**: Checks pass but Node version management remains session-dependent

**2. Missing Dependencies**
- **Issue**: `@eslint/markdown` was in package.json but not installed in node_modules
- **Cause**: Previous `pnpm install` ran with Node v18, which didn't meet dependency requirements
- **Solution**: Switched to Node 24 via nvm, ran `pnpm install` successfully
- **Result**: 133 packages installed/updated, including @eslint/markdown

**3. Script Type Checking Failures**
- **Issue**: `scripts/list-sayno.{mjs,ts}` had TypeScript errors and imported src/lib/cloudinary
- **Problem**: Scripts can't import SvelteKit `$env/*` modules; caused `pnpm check` to fail
- **Solution**: Moved WIP scripts to `../wip-scripts/` (outside project directory)
- **Files moved**: list-sayno.{mjs,ts}, dev-high-mem.sh, api-usage-logger.sh
- **Result**: `pnpm check` now passes with 0 errors

**4. Lint Status**
- **Current**: 97 problems (33 errors, 64 warnings) - all pre-existing
- **Errors in**: CLAUDE.l10n.md, test-auth/, debug APIs, upload_widget_reference.md
- **Our changes**: 0 errors, 0 warnings introduced
- **Decision**: Not blocking deployment; technical debt for separate session

## Key Learnings

1. **Centaur Coding**: Tight conversational loop prevented premature optimization and vibe coding
2. **Mobile-First**: Placing info below upload controls preserved mobile UX priority
3. **Link Text UX**: "collage" as link text felt action-like; info icon (ⓘ) solved discoverability without confusion
4. **Git Hygiene**: Used `git mv` instead of copy for proper history tracking
5. **Dependency Debugging**: Missing modules not always obvious; Node version incompatibility can prevent installs
6. **Persistent Shell Sessions**: Claude Code's Bash tool needs explicit environment setup (nvm)
